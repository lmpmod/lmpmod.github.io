# lmpmod

Плагіни для [Lampa](https://github.com/yumata/lampa).

- **Дорама** — Додає в Lampa розділ з добірками азійських дорам — корейських, китайських і японських. Мод зроблено на основі [плагіна Dorama від xxhekpxx2307](https://xxhekpxx2307.github.io/Plagins/Dorama.js). · `1.8.1` · 2026-11-14 · [dorama.js](https://lmpmod.github.io/dorama.js)
- **Аніме Світ / Anime World** — Додає в Lampa окремий розділ з добірками аніме та китайського дунхуа на даних TMDB. · `1.12.0` · 2026-11-14 · [animeworld.js](https://lmpmod.github.io/animeworld.js)
- **Порядок каналів** — Змінює порядок каналів (рядів) на головній сторінці та сторінках категорій Lampa. · `1.9.0` · 2026-11-14 · [channels-sort.js](https://lmpmod.github.io/channels-sort.js)
- **Альтернативні назви в меню «Уточнити»** — Додає в меню «Уточнити» (в торентах і в онлайн-балансерах) назви різними мовами з TMDB. Налаштування: додаткові мови, транслітерація, альтернативні написання. · `1.1` · 2026-11-14 · [alt-names.js](https://lmpmod.github.io/alt-names.js)
