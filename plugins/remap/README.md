# Ремап епізодів

Зіставляє нумерацію сезонів і серій джерел (Kodik, HDRezka, Animevost тощо) з канонічною нумерацією TMDB — в обидва боки.

## Проблема

Нумерація в джерелах не збігається з TMDB: аніме йде наскрізним списком 1–150, тоді як
TMDB ділить його на 4 сезони; джерело ріже серіал на «арки»; сезон починається не з
першої серії; одне джерело ділить на сезони, інше віддає абсолютні номери. Наслідки:
позначки «переглянуто» стають на не тих серіях, а трекери (Trakt, Simkl, Scrob) пишуть
хибну історію.

## Принципи

- **TMDB — єдине джерело правди:** будь-яка нумерація переводиться в канонічні
  `(season, episode)`.
- **Двосторонній ремап:** при відтворенні серія джерела переводиться в TMDB (для плеєра,
  таймлайну, трекерів), при показі списку — назад, щоб бейджі й прогрес були на місці.
- **Автоматика:** зсув рахується з довжин сезонів у TMDB (`episode_count`), більшість
  аніме не потребує ручних правил.
- **Ізоляція за джерелами:** правило для Kodik не зачіпає Animevost чи торенти.
- **Синхронізація:** правила зберігаються й завантажуються через наявний сервер lampac
  (`/storage/get|set`), без власного сховища.

## Синтаксис правил

```
<tmdb_id>[:<source>]:<type>:<params>
```

`<source>` опційний: без нього правило глобальне. Кілька правил розділяються `;`.

| Тип | Параметри | Приклад | Що робить |
|---|---|---|---|
| `map` | `<from>><to>` | `2>1` | сезон 2 джерела → сезон 1 TMDB, номери серій не змінюються |
| `offset` | `<from>><to>+<N>` або `-<N>` | `5>4+26` | сезон + зсув номера серії |
| `start` | `<from>><to>:<startEpisode>` | `2>2:13` | серія 1 джерела → серія 13 TMDB |
| `abs` | `26,26,12` | `abs:26,26,12` | двонапрямний: наскрізну нумерацію розбиває на сезони TMDB і навпаки |

Короткі форми: `228429:2>1` (глобальний `map`), `228429:kodik:2>1` (`map` для джерела),
`228429:kodik:offset:5>4+26` (повна форма).

## Налаштування

Розділ «Ремап епізодів»: глобальний перемикач, редактор правил, запуск симулятора
(перевірка мапінгу до збереження, одразу з можливістю створити чи змінити правило),
кнопки «Зберегти на сервер» / «Завантажити з сервера».

З пульта: довге натискання «ОК» на серії в балансері → пункт «Ремап епізодів» —
перевірка в один клік.

Синхронізація між пристроями працює, лише якщо вони резолвляться в один акаунт на
сервері (спільний логін або токен) — просто «той самий сервер» без спільної
автентифікації дає кожному пристрою власний анонімний ідентифікатор.

## Публічний API

```javascript
Lampa.EpisodeRemap.forward(card, 'kodik', 5, 1);   // → { season: 4, episode: 27, … }
Lampa.EpisodeRemap.reverse(card, 'kodik', 4, 27);  // → { season: 5, episode: 1, … }
Lampa.EpisodeRemap.openSimulator({ card, balanser: 'kodik', season: 5, episode: 1 });
```

Також доступні `parseRule`, `getAllRules`, `saveRule`, `updateRule`, `deleteRule`,
`exportRulesToServer`, `importRulesFromServer`, `isEnabled`, `version`.
