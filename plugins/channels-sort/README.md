# Порядок каналів

Змінює порядок каналів (рядів) на головній сторінці та сторінках категорій Lampa.

## Що робить

- Дає поставити будь-який канал на першу позицію — навіть той, що Lampa підвантажує
  в 4–5-му батчі: при активному порядку плагін дочікується всіх батчів, рендерить
  відсортовані канали першими, решту підтягує при прокрутці.
- Порядок зберігається **окремо для кожного розділу** (Головна, Фільми, Серіали тощо):
  канали виявляються автоматично при першому завантаженні розділу.
- Канали можна ховати, а порядок — скидати окремо для розділу або для всіх одразу.

## Налаштування

Пункти вбудовані в штатну секцію **«Канали»** (`content_rows`) у налаштуваннях Lampa:

| Пункт | Що робить |
|---|---|
| Редактор порядку | Перетягування каналів, приховування зайвих, вибір активного порядку |
| Скинути все | Очищає збережений порядок і приховані канали для всіх розділів |
| Очистити розділ | Скидає дані лише для обраного розділу |

Стан лежить у `Lampa.Storage` (`channels_sort_*`), тож переживає перезапуск застосунку.
