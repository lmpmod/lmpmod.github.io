# Відкат віртуальних сезонів

Скасовує міграцію таймкодів після видалення плагіна «Без віртуальних сезонів» і повертає Lampa стандартну розбивку на сезони.

## Коли потрібен

Якщо ви поставили `no-virtual-split`, а потім вирішили від нього відмовитись: без цього
плагіна прогрес перегляду лишиться під абсолютними хешами (`S1:E105`), а Lampa після
повернення до стандартної поведінки шукатиме `S2:E1` — бейджі «переглянуто» зникнуть.

## Що робить

Перехоплює `splitEpisodesIntoSeasons`, переносить збережений прогрес назад
(`S1:E105 → S2:E1`, `S1:E106 → S2:E2` …) і викликає оригінальну функцію Lampa, тож
серіал знову ділиться на сезони як раніше. Серіали без прапора `novs_mig_*`
(тобто не мігровані цим плагіном) пропускаються.

## Порядок дій

1. Видалити `no-virtual-split` з розширень Lampa.
2. Підключити `no-virtual-split-undo`.
3. Відкрити кожен серіал, де зберігався прогрес — реверс відбудеться автоматично.
4. Видалити `no-virtual-split-undo` з розширень.

Плагін тимчасовий: тримати його в розширеннях постійно не потрібно.
