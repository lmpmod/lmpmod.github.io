# Нормалізація сезонів

Відмічає переглянутими ті епізоди, яким джерело балансера дало номер сезону S2–S5 замість S1.

## Проблема

Для серіалу з одним сезоном у TMDB різні джерела балансера (lampac) передають той самий
абсолютний номер епізоду під різними сезонами: `S1:E87`, `S2:E87`, `S3:E87`. Lampa
записує таймкод із сезоном від джерела, а бейдж «переглянуто» шукає лише `S1:Exx` —
тому епізоди, переглянуті з S2/S3-джерел, у списку не відмічаються.

## Що робить

При кожному відкритті списку епізодів копіює наявні таймкоди `S2/S3/S4/S5:Exx → S1:Exx`,
якщо `S1:Exx` ще не існує.

Захисти від помилкового копіювання:

- лише для серіалів з `number_of_seasons === 1` у TMDB;
- лише для епізодів, що присутні в поточному списку TMDB;
- ніколи не перезаписує наявний `S1:Exx`.

Сумісний із [no-virtual-split](https://lmpmod.github.io/no-virtual-split.js): виклики
ланцюгуються незалежно від порядку завантаження плагінів, тож можна ставити обидва.

## Де лежать таймкоди

`Lampa.Storage.get('file_view', {})` — об'єкт `{ [hash]: { percent, time, duration, … } }`;
для Premium-акаунтів із синхронізацією — ключ `file_view_<profileId>`. Хеш будується як
`Utils.hash([season_number, episode_number, original_name].join(''))`.
